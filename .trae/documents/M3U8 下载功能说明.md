# M3U8/HLS 视频流下载功能说明

## 📋 功能概述

本扩展现已支持**完整的 M3U8/HLS 视频流下载**功能，可以：

1. ✅ **自动识别 Master Playlist**（多清晰度索引文件）
2. ✅ **弹出清晰度选择对话框**，让用户选择想要的画质
3. ✅ **解析 Media Playlist**，提取所有 ts 分片 URL
4. ✅ **并发下载所有 ts 分片**（默认 6 个并发）
5. ✅ **自动合并 ts 分片**为完整的 mp4 文件
6. ✅ **实时显示下载进度**
7. ✅ **失败重试机制**（每个分片最多重试 3 次）
8. ✅ **支持取消下载**

---

## 🎯 使用方法

### 1. 普通视频文件下载（mp4、webm 等）

- 点击资源列表中的"下载"按钮
- 使用 Chrome Downloads API 直接下载
- 文件保存到浏览器默认下载目录

### 2. M3U8 视频流下载（单清晰度）

- 点击资源列表中的"下载"按钮
- 自动识别为普通 m3u8 文件
- 开始解析并下载所有 ts 分片
- 显示实时进度条
- 下载完成后自动合并为 mp4 文件

### 3. M3U8 视频流下载（多清晰度/Master Playlist） ⭐

- 点击资源列表中的"下载"按钮
- 自动识别为 Master Playlist
- **弹出清晰度选择对话框**
- 选择想要的清晰度（如 1080P、720P、480P 等）
- 开始下载选中的清晰度
- 显示实时进度条
- 下载完成后自动合并为 mp4 文件

## 📊 下载流程

### M3U8 下载流程

```
1. 用户点击下载
   ↓
2. 解析 m3u8 文件
   - 提取所有 ts 分片 URL
   - 计算分片数量
   ↓
3. 并发下载 ts 分片
   - 最多 6 个并发
   - 失败自动重试
   - 实时更新进度
   ↓
4. 合并所有 ts 分片
   - 使用 Blob 合并
   - 生成 mp4 文件
   ↓
5. 触发浏览器下载
   - 下载合并后的 mp4
   - 清理临时文件
```

## ⚙️ 技术参数

### M3U8Downloader 类

**配置参数：**
- `maxConcurrent: 6` - 最大并发下载数
- `retryCount: 3` - 失败重试次数
- 支持相对路径和绝对路径的 ts 分片 URL

**回调函数：**
- `onProgress` - 进度更新回调
- `onComplete` - 下载完成回调
- `onError` - 错误处理回调

**主要方法：**
- `parseM3U8(content, baseUrl)` - 解析 m3u8 文件
- `downloadTs(url)` - 下载单个 ts 分片
- `downloadAllTs(tsUrls)` - 批量下载所有分片
- `mergeTsBlobs()` - 合并所有分片
- `download(url, fileName)` - 主下载流程
- `cancel()` - 取消下载

## 🔍 工作原理

### M3U8 文件解析

M3U8 文件格式示例：
```
#EXTM3U
#EXT-X-VERSION:3
#EXT-X-TARGETDURATION:10
#EXT-X-MEDIA-SEQUENCE:0
#EXTINF:10.0,
segment0.ts
#EXTINF:10.0,
segment1.ts
#EXTINF:10.0,
segment2.ts
#EXT-X-ENDLIST
```

解析器会：
1. 逐行读取 m3u8 文件
2. 跳过所有 #EXT 开头的标签行
3. 提取以 `.ts` 或 `.m4s` 结尾的 URL
4. 处理相对路径和绝对路径
5. 返回完整的 ts 分片 URL 列表

### TS 分片下载

- 使用 `fetch()` API 下载每个分片
- 支持 CORS 跨域请求
- 失败自动重试（指数退避）
- 并发控制（避免过多请求）

### 文件合并

- 使用 `Blob` 对象存储每个分片
- 按顺序合并所有分片
- 创建最终的 `video/mp4` Blob
- 触发浏览器下载

## ⚠️ 注意事项

### 1. 内存使用

- 下载过程会将所有 ts 分片加载到内存
- 大文件（>1GB）可能导致浏览器卡顿
- 建议不要同时下载多个视频

### 2. 跨域限制

- 依赖服务器的 CORS 配置
- 需要 `Access-Control-Allow-Origin` 头
- 某些网站可能禁止跨域访问

### 3. 加密视频

- **不支持 DRM 加密的视频**
- 如果 ts 分片被加密，下载后无法播放
- 需要额外的解密步骤

### 4. 多清晰度

- 当前版本下载默认清晰度
- 如需下载其他清晰度，选择对应的 m3u8 URL

### 5. 直播流

- 不支持直播流下载
- 只支持已完成的点播视频

## 🐛 常见问题

### Q1: 下载进度卡在某个百分比？
**A:** 可能原因：
- 某个 ts 分片下载失败
- 网络连接问题
- 服务器限制
- 解决方法：检查控制台日志，重试下载

### Q2: 下载完成后视频无法播放？
**A:** 可能原因：
- 视频被加密（DRM）
- 部分分片下载失败
- 合并过程出错
- 解决方法：查看控制台错误信息

### Q3: 下载速度很慢？
**A:** 可以调整并发数：
```javascript
// 在 M3U8Downloader 构造函数中修改
this.maxConcurrent = 10; // 增加到 10 个并发
```

### Q4: 提示"CORS 跨域错误"？
**A:** 服务器限制了跨域访问，解决方法：
- 使用支持 CORS 的代理
- 或改用外部下载工具

### Q5: 如何取消下载？
**A:** 当前版本暂未提供 UI 取消按钮，可以：
- 刷新页面取消下载
- 后续版本会添加取消按钮

## 📝 技术细节

### 并发下载实现

```javascript
async downloadAllTs(tsUrls) {
  const downloadQueue = [...tsUrls];
  const inProgress = new Map();
  
  while (inProgress.size < this.maxConcurrent && downloadQueue.length > 0) {
    const url = downloadQueue.shift();
    const promise = this.downloadTs(url);
    inProgress.set(url, promise);
  }
}
```

### 失败重试机制

```javascript
async downloadTs(url, retryCount = 3) {
  for (let i = 0; i < retryCount; i++) {
    try {
      const response = await fetch(url);
      if (!response.ok) throw new Error(`HTTP ${response.status}`);
      return await response.blob();
    } catch (error) {
      if (i === retryCount - 1) throw error;
      await new Promise(resolve => setTimeout(resolve, 1000 * (i + 1)));
    }
  }
}
```

## 🚀 性能优化建议

1. **调整并发数**
   - 网络好：增加到 10-15
   - 网络差：减少到 3-5

2. **大文件处理**
   - 考虑使用流式处理
   - 或分批次下载合并

3. **内存管理**
   - 下载完成后及时清理 blob
   - 避免同时下载多个视频
